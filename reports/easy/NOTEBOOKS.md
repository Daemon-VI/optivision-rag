# Easy-mode validation notebooks

Generated by `python scripts/make_easy_validation.py` (deterministic; `tests/test_easy_validation.py` fails if a
committed notebook is stale). Each clones branch `easy-mode`, then a guard cell stops it before any install or GPU
work unless `reports/easy/PREREG_EASY.frozen.json` holds the parts listed and every frozen file still has its
recorded SHA-256. Each fits one 11 h Kaggle 2xT4 session (deadline 11 h) and resumes from
its own output. Ingest: `python scripts/easy_validation/ingest.py <zip>`.

Prereg parts: 1 = rule, units, thresholds (`PREREG_EASY.md`); 2 = probes, hard set, seeds (`PREREG_EASY_PART2.md`);
3 = DT campaign and practice-question allowance (`PREREG_EASY_PART3.md`). All three are DRAFT, NOT FROZEN.
